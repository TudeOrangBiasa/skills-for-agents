`/whips` gains two playbooks. `refactor` pins current behavior first, subtracts before it reshapes, migrates every caller and deletes the old API in one wave, and keeps the change only when the code got simpler to read. `prototype` settles a fork by building the real options as throwaway and observing them, so the agent decides from evidence instead of stopping to ask; the chosen direction hands off to `feature`. Both are rows in the router table and named in `guide`.
