New model-invoked `/user-manual` skill: generate a user manual (guide book, panduan pengguna) from a running web app with one deterministic command. Shots clip to content targets with sticky and fixed element handling, edges auto-trim with a fixed margin, selector-based annotations resolve to sidecar coordinates, and the build fails on blank-band screenshots, orphan captions, stale captures, or budget overruns. Ships a working CLI (dependency-free trim and QA plus Playwright capture and PDF), print assets, and a fixture.
