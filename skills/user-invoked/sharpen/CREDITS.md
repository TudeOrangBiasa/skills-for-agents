# Credits

Prompt-sharpening flow adapted from [Lauren Tan (poteto)](https://github.com/poteto)'s `sharpen` in `pstack` ([cursor/plugins](https://github.com/cursor/plugins), folder `pstack`): make the task deeper, not bigger, then rewrite the prompt. Interview beats guessing, assumptions get marked before the run, and sharpening never executes the task itself. Copied in, not depended on, so standalone installs keep working without the upstream repo.
