# Credits

Routed-playbook design adapted from [Lauren Tan (poteto)](https://github.com/poteto)'s `pstack` ([cursor/plugins](https://github.com/cursor/plugins), folder `pstack`): the `poteto-mode` router that matches a task to a playbook, opens its steps verbatim as a todo, routes to leaf skills as steps fire, and delegates implementation to fresh subagents with consolidated scope under a verifying director. The `opening-a-pr` playbook adapts pstack's `opening-a-pr` (worktree per unit, small ordered commits, Conventional Commits titles, base-branch stacks, no babysit on open) with readiness flipped to always draft. The `triage` review mode adapts pstack's `bugbot-triage` fix, dismiss, ask rubric. Playbook shapes (feature checkpoint, bug repro-first, swarm and arena fan-out, interrogate panels, show-me-your-work trail, benny triage plus reproduce-and-fix automations) paraphrased into this repo's HIT flow and skill names. OMP director plus worker mechanics, advisor severities, and hooks gates per [oh-my-pi](https://github.com/can1357/oh-my-pi) docs (`vibe-mode.md`, `advisor-watchdog.md`, `hooks.md`). Copied in, not depended on, so standalone installs keep working without the upstream repos.
