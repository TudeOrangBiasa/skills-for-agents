# Credits

Transcript mining into skill edits, the three-lens reviewer fan-out (judgment, tooling, divergent) with a synthesizer into Accepted / Rejected / Backlog, the skill-was-used scoping rule with `tune description` routing, the structural-mechanism check, and the present-then-approve apply gate adapted from the pstack `reflect` skill set by poteto ([Lauren Tan](https://x.com/poteto), MIT). Rewritten to this repo conventions: no harness pins (no `subagent_type`, no model names; reviewers and synthesizer follow the repo model map with a two-pass fallback on single-model harnesses), transcript lookup follows the harness store for this workspace only with a digest fallback, reviewer prompts live in `agents/` instead of `references/`, substantive edits route through the whips `authoring-a-skill` playbook and small PRs through `opening-a-pr`. Copied in, not depended on, so standalone installs keep working without the upstream repo.
