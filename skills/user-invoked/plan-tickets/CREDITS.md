# Credits

Forked from [Matt Pocock](https://github.com/mattpocock)'s `to-tickets` ([mattpocock/skills](https://github.com/mattpocock/skills)). Breaks a plan, spec, or conversation into tracer-bullet tickets, each declaring its blocking edges. Copied in, not depended on, so standalone installs keep working without the upstream repo.

Local rename history: `to-tickets` became `plan-tickets` in #175 (stage-prefix scheme); upstream source names above are unchanged.
