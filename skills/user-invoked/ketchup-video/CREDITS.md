# Credits

The catch-up video shape (short subtitled slide video over the `/ketchup` window, one point per slide, burned-in subtitle strip, timed holds, action items as text under the video) adapted from the pstack skill set by poteto ([Lauren Tan](https://x.com/poteto), MIT). Rewritten to this repo conventions: no harness-specific paths, plain-words voice per `unslop` instead of `/bro`, and a text fallback when the harness has no authored-slide video render path. Copied in, not depended on, so standalone installs keep working without the upstream repo.
