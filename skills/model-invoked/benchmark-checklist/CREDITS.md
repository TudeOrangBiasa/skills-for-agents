# Credits

Ballpark rule, pre-run setup, the seven vetting questions, and the verdict-first report adapted from the pstack `benchmark-checklist` skill set by poteto ([Lauren Tan](https://x.com/poteto), MIT). Rewritten to this repo conventions: referenced by `perf-issue` and `hillclimb`, generic tooling (no Linux-only commands as requirements), no harness assumptions. Copied in, not depended on, so standalone installs keep working without the upstream repo.
