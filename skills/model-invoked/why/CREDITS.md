# Credits

Fan-out investigators with one source each, the gather-don't-conclude contract, and the five confidence tiers (Direct, Supported, Inferred, Speculative, Unknown) with phrasing guide adapted from the pstack skill set by poteto ([Lauren Tan](https://x.com/poteto), MIT). Rewritten to this repo conventions: no model pins, no MCP assumption (sources run when a tool reaches them), git plus `gh` as the guaranteed source. Copied in, not depended on, so standalone installs keep working without the upstream repo.
