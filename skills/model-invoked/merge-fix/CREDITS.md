# Credits

Forked from [Matt Pocock](https://github.com/mattpocock)'s `resolving-merge-conflicts` ([mattpocock/skills](https://github.com/mattpocock/skills)), renamed to `merge-fix`. Works an in-progress merge or rebase conflict hunk by hunk, resolving by intent traced to each side's primary source. Copied in, not depended on, so standalone installs keep working without the upstream repo.
